# Bitácora de uso de IA
Actividad 1 – Diseño del front-end

Rol: Desarrolladora del proyecto.

Tarea: Diseñar y crear una plantilla de tarjetas para mostrar los productos de la cafetería.

Contexto: Proyecto Django Café Aroma, utilizando Bootstrap 5 y Django Template Language. Cada tarjeta debía mostrar el nombre del producto, categoría, precio y disponibilidad, además de las opciones para visualizar, editar y eliminar productos.

Formato: Plantilla HTML con etiquetas DTL, extendiendo base.html.

Resultado obtenido: Creé la vista de productos mediante tarjetas organizadas en una grilla, incorporando la información de cada producto y las opciones correspondientes para administrar su contenido.

Actividad 2 – Configuración y depuración de MySQL

Rol: Desarrolladora responsable de la configuración del proyecto.

Tarea: Configurar la conexión entre Django y MySQL y solucionar los problemas que aparecieron al ejecutar las migraciones.

Contexto: Proyecto Café Aroma desarrollado con Django, utilizando MySQL 8, una base de datos llamada cafeteria_db, el servidor local 127.0.0.1, el puerto 3306 y el conector mysqlclient.

Formato: Configuración en settings.py y ejecución de comandos desde la terminal.

Resultado obtenido: Configuré los parámetros de conexión con MySQL, revisé la configuración del proyecto y trabajé con los comandos necesarios para generar y aplicar las migraciones de la base de datos.

Reflexión

Realicé el desarrollo del proyecto Café Aroma trabajando en el diseño de las plantillas, la organización de los productos y la configuración de la base de datos. También implementé las funcionalidades necesarias para administrar los productos y corregí los problemas que aparecieron durante el desarrollo. Esto me permitió aplicar los conocimientos adquiridos sobre Django, Bootstrap y MySQL.
